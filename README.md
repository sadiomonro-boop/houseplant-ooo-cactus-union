A program that writes the funniest houseplant out-of-office auto-reply (108 characters) for make.fun's The Houseplant Out-of-Office bounty.

## The entry

> On leave. They rotated me for 'even growth' and now I face the wall. I refuse to photosynthesise. No emails.

The line was picked by a blind test: 8 candidate replies judged pairwise against each other and against strong rival lines, using the judge criteria published with the bounty (houseplant OOO voice first, then surprise, plant life driving the joke, tightness, originality).

## Run it

```sh
python3 main.py
```

This writes the reply to `/output/entry.txt`. Deterministic, standard library only, no network.
